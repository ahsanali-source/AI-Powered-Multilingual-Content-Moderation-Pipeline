# AI-Powered-Multilingual-Content-Moderation-Pipeline
A multilingual NLP content moderation pipeline fine-tuned on transformer models (XLM-RoBERTa/mBERT) to detect hate speech, toxicity, and cyberbullying in Roman Urdu and code-mixed text. Deployed with FastAPI for real-time inference, enabling automated community guideline enforcement and Trust &amp; Safety monitoring at scale.
